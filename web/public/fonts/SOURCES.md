## Subsets

Each face is split in two. The core file has Basic Latin, Latin-1, General Punctuation, the UI's arrows and check marks, and every code point at least 0.001% frequent in `cap-glyphs.json` (67,403 cases from 401 volumes, one per reporter). The ext file has every other sampled code point the font has, and loads only when a page uses one. Hinting is dropped; OpenType features kept: kern, liga, lnum, onum, tnum, pnum, smcp, c2sc, frac, sups (where the font has them).

## Static or variable

- **Source Serif 4**: Static. The variable font's opsz axis makes its two files 2.2x the four statics combined.
- **Source Sans 3**: Variable (wght 200-900): smaller than the four statics, and the UI's 500 and 600 weights are real.
- **Source Code Pro**: Variable (wght 200-900): smaller than the four statics.
- **Charis**: Static; Charis has no variable release.
- **IBM Plex Mono**: Variable, wght limited to 400-700: smaller than the four statics.
- **Merriweather**: Static instances (wdth 100, opsz 16) of the variable font: the variable files with opsz are 1.6x the four statics.
- **Merriweather Sans**: Static instances of the variable font, which is 1.2x the four statics.
